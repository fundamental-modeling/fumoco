# fumoco (app)

The Fumoco editor itself — see the [top-level README](../README.md) for
what it is, getting started, and the repository layout.

```sh
npm ci            # install dependencies
npm start         # dev server on http://localhost:4200
npm test          # build + QUnit suite (add `-- --launch Chromium` without Chrome)
npm run lint      # eslint, template-lint, stylelint, prettier
npm run build     # production build into dist/
```
